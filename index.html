关于 FilmArchive

FilmArchive 是为胶片摄影爱好者打造的胶卷档案管理工具，记录每一卷胶片从装填、拍摄、冲洗到扫描归档的完整旅程。

  • 胶卷档案：品牌型号、ISO、画幅、逐帧曝光参数、拍摄地图
  • 冲洗管理：药剂记录、暗房分阶段计时器、冲洗历史统计
  • 负片预览：摄像头实时负片转正
  • 扫描归档：扫描件整理与整卷索引图（Contact Sheet）生成
  • 纯本地存储，零数据收集，可选 iCloud 私有同步

常见问题

  • Pro 订阅包含什么？无限胶卷档案、索引图去水印与全部样式、全部负片预设与橙罩微调、自定义冲洗模板、冲洗历史统计。免费版可管理 5 卷，核心功能完整可用。
  • 如何取消订阅？iPhone「设置 → Apple ID → 订阅」中管理或取消，详见订阅条款。
  • 换手机数据会丢吗？不会。使用设置页「导出全部数据」生成 JSON 备份，新设备导入即可；也可开启 iCloud 同步。
  • 恢复购买失败？请确认使用购买时的同一 Apple ID，并在设置页点击「恢复购买」。
