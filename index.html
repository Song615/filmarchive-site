关于 FilmArchive

FilmArchive 是为胶片摄影爱好者打造的胶卷档案管理工具，记录每一卷胶片从装填、拍摄、冲洗到扫描归档的完整旅程。

  • 胶卷档案：品牌型号、ISO、画幅、逐帧曝光参数、拍摄地图
  • 冲洗管理：药剂记录、暗房分阶段计时器、冲洗历史统计
  • 负片预览：摄像头实时负片转正，高级微调（Pro）
  • 扫描归档：扫描件整理与整卷索引图（Contact Sheet）生成
  • 纯本地存储，零数据收集，密码加密备份导出

常见问题

  • Pro 订阅包含什么？ 无限胶卷档案、索引图去水印与全部片基/纸色样式、自定义冲洗阶段模板、带统计的冲洗记录档案库、负转正高级微调。负转正基础功能与密码加密备份为免费功能；免费版可管理 2 卷，核心功能完整可用。
  • 如何取消订阅？ iPhone「设置 → Apple ID → 订阅」中管理或取消，详见订阅条款。
  • 换手机数据会丢吗？ 不会。使用设置页「导出全部数据」生成密码加密的备份文件，新设备导入时输入同一密码即可。
  • 恢复购买失败？ 请确认使用购买时的同一 Apple ID，并在设置页点击「恢复购买」。

About FilmArchive

FilmArchive is a film-roll archive tool for analog photography enthusiasts — it records every roll's full journey from loading and shooting to developing and scanning.

  • Roll archive: film stock, ISO, format, per-frame exposure data, shooting map
  • Developing: chemical records, staged darkroom timer, developing history stats
  • Negative preview: real-time negative-to-positive camera viewer
  • Scan archive: organize scans per roll and generate contact sheets
  • Fully local storage, zero data collection, password-encrypted backup export

FAQ

  • What does Pro include? Unlimited roll archive, watermark-free index sheets with all film-base and paper styles, custom developing stage templates, the developing records archive with statistics, and pro-level negative tuning. The basic negative-to-positive viewer and password-encrypted backups are free for everyone; the free version manages up to 2 rolls with full core functionality.
  • How do I cancel my subscription? Manage or cancel in iPhone Settings → Apple ID → Subscriptions. See Subscription Terms.
  • Will I lose data when switching phones? No. Export a password-encrypted backup via Settings → Export All Data and import it on the new device with the same password.
  • Restore Purchases failed? Make sure you are signed in with the same Apple ID used for the purchase, then tap Restore Purchases in Settings.

FilmArchive について

FilmArchive はフィルム写真愛好家のためのフィルムアーカイブツールです。装填から撮影・現像・スキャンまで、1 本ごとの旅路を記録します。

  • フィルムアーカイブ：銘柄・ISO・判型・コマごとの露出記録・撮影マップ
  • 現像管理：薬品記録、暗室ステージタイマー、現像履歴の統計
  • ネガプレビュー：カメラでのリアルタイム・ネガポジ反転
  • スキャン整理：ロールごとの整理とコンタクトシート生成
  • 完全ローカル保存・データ収集ゼロ・パスワード暗号化バックアップ書き出し

よくある質問

  • Pro の内容は？ 無制限のフィルムアーカイブ、透かし除去と全スタイルのインデックスシート、カスタム現像テンプレート、統計付き現像記録アーカイブ、ネガ→ポジの詳細調整。ネガポジ反転の基本機能とパスワード暗号化バックアップは無料機能です。無料版は 2 本まで、コア機能はすべて利用可能です。
  • 解約方法は？ iPhone の「設定 → Apple ID → サブスクリプション」から管理・解約できます。詳細はサブスクリプション規約をご覧ください。
  • 機種変更でデータは消えますか？ 消えません。設定の「全データ書き出し」でパスワード暗号化のバックアップを作成し、新しい端末で同じパスワードを入力して読み込めます。
  • 購入を復元できません 購入時と同じ Apple ID でサインインしていることを確認し、設定で「購入を復元」をタップしてください。
